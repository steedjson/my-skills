```markdown
- 搜索/筛选：<字段>
- 表格列：<列1>、<列2>、…（共 N 列）

```

## 合并规则

1. 逐页 innerText 为主干（字段名、按钮文案、状态值是文字证据，最可信）。
2. 视觉分析补「列结构 / 颜色语义（粉底=待填、灰底=联动计算）、布局」——这些 innerText 拿不到或顺序不对。
3. 文字与视觉冲突时：以文字为准，差异写进「疑点清单」。
4. 数字/金额演示值照抄并注明「演示数据」。
