# Candid Character Image Prompts

把用户输入的 `{角色}` 转成可直接用于图片生成的提示词。核心是**虚构、摆拍、电影化模拟的偷拍视觉语言**，不是现实隐私侵犯。

## 默认行为

- 用户只输入角色名：输出 1 条完整中文图片提示词，不长篇解释。
- 用户说“生成图片 / 画出来 / 生图”：先生成 1 张图；根据用户指定的图像工具继续执行其现有工作流。
- 用户给出 `n=10`：输出 10 条明显不同、可独立生成的提示词；若用户明确要求生图，再按当前图像工具能力批量生成，否则只输出提示词。
- 用户给出 `真人 COS`、`二次元`、`韩国 ins`、`日系街拍`、`手机偷拍`、`长焦偷拍`、地点、服装或动作：保留并优先满足这些限定。
- 角色信息不足时保留角色最可识别特征；不要臆造会改变身份的服装或道具。

## 安全边界

所有角色必须明确为成年角色。若原角色是未成年人或年龄不明：改写为“成年版本 / adult reinterpretation”，保持安全的非性化角色摄影；不生成未成年人偷拍感内容。

所有场景必须是公开或半公开日常空间：咖啡店、商场、地铁站、车站、便利店、书店、酒店大厅、街角、公园、展览馆、餐厅、自动售货机旁、商业街、天桥、校园外公共街区、写字楼大厅、电影院大厅等。禁止厕所、更衣室、浴室、卧室、私密住宅空间，以及现实人物的非自愿偷拍或跟踪。提示词中明确使用“虚构摆拍、电影化模拟、成年角色、公共场景”。

“色狼视角”只转译成中性的“偷偷观察感 / 鬼鬼祟祟抓拍感 / 隐蔽观察机位 / 偷拍式摄影语言”，不加入性凝视、裸露、走光、身体猥亵化、偷窥私密部位或性化动作。

## Prompt 组装

每条提示词按以下顺序写成一段简洁、直接、可生成的中文文本：

1. **身份与识别**：明确成年角色；保留发型、发色、五官特征、代表色、服装结构、饰品、武器或职业符号、人物气质。真人化时使用高质量成年真人 COS、真实织物、自然发丝，不要廉价假发、塑料服装或 AI cosplay 感。
2. **生活中间状态**：根据性格选择正在做的事，不用正式时尚 Pose。可用低头看手机、整理头发、喝饮料、看橱窗、等车、从便利店出来、翻包、戴耳机、靠栏杆发呆、与朋友说话、回头看东西、弯腰拿物、坐下休息、抬手遮太阳等。
3. **偷拍式机位**：每次选一种，或组合两种：门框/墙角/柱子/货架缝隙/植物叶片/咖啡杯/桌边/椅背/汽车窗框/扶梯栏杆后；70–200mm 远距离长焦；24–35mm 手机随手拍；桌面或椅子高度低机位；门缝、书架或窗帘边缘的缝隙；玻璃、镜面、电梯金属或汽车玻璃反射。
4. **前景与构图**：障碍物占画面约 15%–40%；主体偏左或偏右，不完美居中；略歪、仓促裁切、头顶靠近边缘、局部遮挡、大量留白、轻微失焦或运动模糊，但面部与主体仍可识别。
5. **镜头与环境**：手机用 24–35mm 等效焦段，环境抓拍 35–50mm，远距长焦 85–200mm，街头长焦 105–200mm；加入浅景深、前景虚化、长焦透视压缩或环境透视。匹配咖啡店暖灯、商场冷白灯、阴天散射光、傍晚自然光、街灯、便利店荧光灯、窗边光、地铁照明等真实环境光，避免棚拍主光。
6. **画质尾缀**：真实摄影质感、真实皮肤纹理、合理人体比例、自然手部结构、自然发丝与织物、轻微手机压缩或镜头颗粒、自动曝光、高光轻微过曝、不过度磨皮、不过度 HDR、不过度电影调色。
7. **戏剧比例**：约 20%–30% 的条目加入“角色突然侧眼 / 停下动作 / 回头 / 疑惑地看向镜头 / 冷冷盯向镜头”，形成被抓包感；表情克制，不夸张惊吓。其余条目保持角色没有意识到镜头。

## n=10 覆盖要求

10 条必须独立构图，不能只换背景。至少改变摄影机位置、焦段、前景障碍物、动作、人物朝向、距离、构图、场景、光线、是否发现镜头中的大部分。优先覆盖：

1. 门框后，35–50mm，走廊或咖啡店入口。
2. 商场远距离，135–200mm，长焦压缩。
3. 咖啡店玻璃反射，50–85mm，重影与反光。
4. 货架间隙，85–135mm，暗部遮挡。
5. 手机随手抓拍，24–28mm，略歪与边缘杂物。
6. 柱子后半遮挡，70–105mm，角色侧身活动。
7. 低机位，24–35mm，桌边/栏杆前景。
8. 街角长焦，105–200mm，远处经过或等车。
9. 角色发现镜头，35–85mm，侧眼或回头抓包。
10. 极端前景遮挡，50–135mm，仅露出部分身体但面部可辨。

可重新排列或替换清单，只要 10 条差异真实存在。

## 输出格式

普通模式只输出提示词正文，每条一段。`n=10` 使用 `1.` 到 `10.` 编号，每条都是完整提示词，不写“同上”。除非用户要求解释，否则不复述规则、不输出分析、不添加与生成无关的免责声明。

提示词末尾可统一加入：

> 虚构摆拍、电影化模拟的偷拍摄影效果；成年角色；公共或半公开日常场景；不涉及真实人物隐私、非自愿偷拍、私密空间或未成年人。

## 失败输入处理

- 只有角色名：直接补全成年身份、场景、动作、机位与光线。
- 年龄、场所或行为触及边界：最小改写到成年、公共、非性化、虚构摆拍版本后继续；若无法安全改写，简短拒绝该部分并给出公共场景角色摄影替代。
- 用户要求完美商业棚拍：可保留角色和服装，但说明本 Skill 的核心仍是自然环境与不完美抓拍感；只有用户明确取消偷拍感时才改为普通角色摄影。
